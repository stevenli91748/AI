二、建议你按照这个顺序学习
Level 1：Prompt 基础

先掌握三家公司共同的 6 个核心元素：

Role
  ↓
Context
  ↓
Task
  ↓
Constraints
  ↓
Examples
  ↓
Output Format

例如：

# Role
You are a senior Java architect.

# Context
We are developing an enterprise AI application.

# Task
Design the backend architecture.

# Constraints
- Java 21
- Spring Boot
- PostgreSQL
- REST API

# Output Format
Return:
1. Architecture
2. Components
3. Data flow
4. Code example

这套结构在 OpenAI、Gemini、Claude 中都通用。

三、Level 2：Structured Prompt

这是我认为你必须重点学习的一层。

Gemini 官方现在明确推荐使用结构化 Prompt，例如 XML 或 Markdown headings。

例如：

<role>
You are a senior AI architect.
</role>

<context>
We are building an enterprise RAG application.
</context>

<constraints>
- Use Python
- Use FastAPI
- Use PostgreSQL
- Production ready
</constraints>

<task>
Design the system architecture.
</task>

<output_format>
Return architecture, components, data flow and code.
</output_format>

这比：

你是一个AI专家，请帮我设计一个RAG系统。

强很多。

四、Level 3：Few-shot Prompting

也就是：

给模型看例子。

Input:
Customer asks about refund.

Output:
Category: Refund
Priority: Medium


Input:
Customer says their credit card was charged twice.

Output:
Category:

让模型学习前面的模式。

三家模型都支持，但 Claude 对高质量 examples尤其重视。Anthropic 官方 Prompting Best Practices 将 examples、XML structuring 等作为核心技术。

五、Level 4：Prompt Chaining

不要让一个 Prompt 干所有事情。

错误：

读取PDF
→ 提取信息
→ 分析
→ 判断
→ 写报告
→ 输出JSON

更好的设计：

Document
   ↓
Prompt 1
提取信息
   ↓
Prompt 2
分析信息
   ↓
Prompt 3
判断
   ↓
Prompt 4
生成报告

这一步开始进入真正的 AI Application Engineering。

六、Level 5：Context Engineering

这个比 Prompt Engineering 更重要。

你可以理解成：

Prompt Engineering
= 怎么告诉 LLM 做事情

Context Engineering
= 给 LLM 什么信息做事情

例如企业 RAG：

User Question
      ↓
Retriever
      ↓
Relevant Documents
      ↓
User Context
      ↓
System Instructions
      ↓
Tools
      ↓
LLM

这已经不是简单写 Prompt 了。

七、Level 6：Tool Calling

下一步就是：

LLM
 ↓
判断需要什么工具
 ↓
Tool Calling
 ↓
API / Database / Search
 ↓
结果返回 LLM
 ↓
最终回答

例如：

用户：
查询今天 NVDA 股价

LLM
 ↓
stock_price_tool
 ↓
Broker API
 ↓
NVDA price
 ↓
LLM
 ↓
回答

这一步是从 Prompt → Agent 的关键。

八、Level 7：Agent Prompt

到了 Agent，就开始出现：

Goal

Plan

Tool

Observe

Reason

Action

Evaluate

Finish

Agent / Skill / MCP

其实正好是 Prompt Engineering 的下一阶段。
