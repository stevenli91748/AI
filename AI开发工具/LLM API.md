# **LLM API 有哪几种需要学习？官方资源大全（2026）**

如果你的目标是成为美国 **AI Engineer / AI Application Developer**，我建议重点学习 6 家主流 LLM API，再了解其他模型服务平台。

首先要理解：

**LLM API 是应用程序调用大语言模型的接口。**

例如，你使用 Python + FastAPI 开发 AI 应用，通过 API 调用 GPT、Claude 或 Gemini，让应用具备：

- AI 对话
- 文档总结
- 代码生成
- RAG 知识库问答
- AI Agent
- Function Calling / Tool Calling
- 多模态图像、音频处理

## **三、LLM API 有哪些类型？**

不只是 Chat API。AI Engineer 应该掌握下面这些接口。

| API 类型               | 功能         | 重要程度   |
| -------------------- | ---------- | ------ |
| Chat / Responses API | AI 对话、文本生成 | 必须     |
| Embeddings API       | 文本向量化      | 必须     |
| Function Calling     | 调用外部工具     | 必须     |
| Structured Outputs   | JSON 结构化输出 | 必须     |
| Streaming API        | 实时流式输出     | 必须     |
| Rerank API           | 搜索结果重新排序   | RAG 推荐 |
| Image API            | 图像理解、生成    | 推荐     |
| Audio API            | 语音识别、语音生成  | 推荐     |
| Realtime API         | 实时语音交互     | 推荐     |

## **四、学习顺序：不要同时学习所有 API**

我建议采用下面的顺序：

1. **第一阶段：OpenAI API**

   学会 API Key、SDK、Responses、Streaming、Tool Calling、Embeddings。

   核心基础
2. **第二阶段：Anthropic Claude API**

   学习 Messages API、Tool Use、Prompt Caching。
3. **第三阶段：Google Gemini API**

   学习多模态、图片、视频、长上下文。
4. **第四阶段：DeepSeek + Grok + Mistral**

   学习不同模型供应商的接口兼容、模型切换和成本比较。
5. **第五阶段：Amazon Bedrock**

   学习企业级模型部署、IAM、AWS 集成。

## **六、最终学习优先级**

如果时间有限，我建议：

| 1   | OpenAI API↳             |
| 2   | Claude API              |
| 3   | Gemini API              |
| 4   | DeepSeek API            |

**特别提醒：** 不需要把 10 家厂商的 API 全部学到精通。先掌握 OpenAI 的 API 开发模式，再学习 Claude 和 Gemini 的原生接口，之后重点掌握多模型切换、统一接口、成本控制和错误处理。

## **七、我建议你的第一个实战项目**

适合 GitHub 求职作品集

**Multi-LLM AI Platform（多模型 AI 平台）**

实现功能：

1. 同一个聊天界面切换 GPT、Claude、Gemini。
2. 支持 Streaming 实时回答。
3. 支持上传 PDF 文档。
4. 支持 RAG 知识库。
5. 支持 Function Calling。
6. 保存聊天记录到 PostgreSQL。
7. 支持用户登录和权限管理。
8. Docker + AWS 部署。

这个项目能综合展示 LLM API、RAG、Backend、Frontend 和 Cloud Deployment 能力。

**我的建议：先把 OpenAI API 学透，再做多模型平台。** 这比同时浅尝 10 个 API 更有求职价值。
