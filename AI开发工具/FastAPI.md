1. **快速开始（Quickstart）**
   - [FastAPI Quickstart](https://fastapi.tiangolo.com/tutorial/?utm_source=chatgpt.com)
   - 学习创建第一个 API、路径参数、请求参数等。

2. **用户指南（User Guide）**
   - [FastAPI User Guide](https://fastapi.tiangolo.com/tutorial/?utm_source=chatgpt.com)
   - 包括：
     - Pydantic 数据验证
     - Dependency Injection（依赖注入）
     - Security（JWT/OAuth2）
     - Middleware
     - Background Tasks
     - WebSocket
     - 文件上传
     - 生命周期（Lifespan）

3. **部署（Deployment）**
   - [FastAPI Deployment Guide](https://fastapi.tiangolo.com/deployment/?utm_source=chatgpt.com)

4. **最佳实践**

结合你之前想走的美国 AI Engineer 路线，我建议 FastAPI 学习顺序如下：

1. Python 基础
2. FastAPI 基础（CRUD、REST API）
3. Pydantic
4. SQLAlchemy + PostgreSQL
5. JWT/OAuth2 登录认证
6. Async（async/await）
7. Docker
8. Redis
9. Celery 或 Background Tasks
10. LangChain / LangGraph
11. RAG（向量数据库）
12. MCP（Model Context Protocol）
13. AWS 部署（ECS、EC2、Lambda 等）

这是目前美国大多数 AI 应用开发岗位最常见的后端技术栈。
