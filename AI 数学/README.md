
# 数学主要分类有50大类：
1算术（有理数的加减乘除和四则混合运算）
2代数（研究字母代替数字，包括代数式，代数方程，代数函数，不等式，复数，数列，向量，行列式8大部分）
3平面几何（平面图形，主要有三角形，四边形，圆）
4三角（三角函数，包括三角函数的图像，三角公式和三角方程）
5立体几何（立体图形的性质，包括多面体，旋转体，棱台，棱锥等）
6解析几何（用代数方法解几何图形，主要有直线方程，曲线方程，圆方程，抛物线和双曲线）
7线性代数（代数的线性空间和线性变换）
8微积分（函数的微分和积分，包括极限，导数，积分，多元函数，无穷级数等）
9复变函数（包括柯西方程，黎曼方程，柯西积分，柯西公式，解析开拓，解析函数，保角映射）
10微分几何
11微分方程（常微分方程和偏微分方程）
12积分方程（对未知函数的积分运算）
13变分学（用变分方法解决边值问题）
14统计学 15概率学 16运筹学 17逻辑学 18集合学 19组合和排列学
20拓扑学（几何图形或连续改变形状后保持不变的学科）
21数论（主要研究整数的性质：哥德巴赫猜想）
22图论（通路，回路，树，割集，网路）
23组合论（生成函数，伯努利多项式，反演公式，递归，线秩项秩）
24随机过程论（鞅论、马氏链、Q过程、Brown运动、马氏过程）
25控制理论（古典控制理论，现代控制理论）
26最优化方法（线性规划，凸函数）
27有限元法（基函数）
28特殊函数（伽马函数，贝塔函数，西格玛函数，贝塞尔函数）
29张量学 （矢量、标量和其他张量之间的线性关系的多线性函数）
30积分变换学（傅里叶变换、拉普拉斯变换）
31代数结构（群、环、域、格、模、域代数和向量空间等等）
32科学计算 （建立数学模型、建立求解的计算方法和计算机实现）
33算法学 （递归函数的应用）
34计算机语言
35数据库
36软件工程学
37信息论（
38数学建模
39数值分析（用计算机求解数学计算问题的数值计算方法）
40应用数学
41泛函分析（研究无限维向量空间上的泛函，算子和极限理论）
42模糊数学
43量子数学
44离散数学
45物理数学
46级数理论
47计算数学
48球面几何（包括球面三角等）
49高等几何学
50数学史
